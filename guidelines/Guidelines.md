# Moyusi 开发约束

开始修改产品前，先阅读 `docs/README.md`，再按任务阅读对应 PRD、体验或架构文档。

## 产品边界

- 产品一级导航只保留「模型广场」与「工作台」；Key、模型部署、工作环境、用量、账本、设备和账户作为工作台子域。
- 模型广场可以收录广泛供给，但只有签约、可售、可计量、可结算的 RouteOffer 才能使用统一余额。
- 桌面端负责本地工具配置、系统安全存储、本地 BYOK 与本地代理。
- Gateway 负责认证、协议、路由、流式转发与计量，不直接修改余额。
- 请求日志不是账本；页面状态不是事实源；Provider、模型、线路和价格不是同一实体。
- BYOK 费用由外部供应商结算；不得从 Moyusi 余额中伪扣，也不得把本地估算表述为供应商账单。
- MVP 聚焦语言/代码模型、Codex 与 Claude Code。允许最小的私有 MCP/Skills/Prompts Profile 迁移，但不要主动加入图片/视频工作台、邀请返佣、公共 MCP/Skills 市场或复杂团队功能。
- 区分开放权重模型、开放源代码推理引擎和闭源 API；未经许可证与来源核验不得笼统标记“开源”。
- 模型工件、ServingRevision、算力端点、RouteOffer 和价格分别建模；开放模型请求必须可追到权重、引擎、量化和硬件版本。

## 安全

- 禁止在源码、fixture、截图、日志或文档中放入真实 API Key、Cookie、支付凭证或上游密钥。
- 示例凭证使用明显占位符，例如 `<MOYUSI_API_KEY>`，不要伪造看似真实的 `sk-...` 值。
- 平台 Key 明文只在创建时展示一次；服务端保存 keyed digest，不保存可逆明文。
- 第三方 BYOK 默认只保存在桌面系统安全存储，不上传云端。
- WorkspaceProfile 和导出包只保存 Secret reference，不包含明文 Secret；目标软件必须重新绑定授权。
- MCP Server 按外部执行面管理，Skills 中的脚本按代码管理；来源、权限、签名、扫描、确认和审计不可省略。
- 记忆和知识库遵守作用域、敏感度、ACL、保留与删除规则；目标索引不得扩大源文档权限。
- 桌面导入使用短时、单次、设备绑定的 ImportGrant；禁止把 Key 放入 deep link。
- 默认不持久化请求/响应正文；任何例外必须有单独授权、加密、期限和删除能力。
- 本地代理默认只监听 loopback；外部监听需要显式风险确认。

## 计费与数据

- 金额使用整数最小货币单位或 Decimal，禁止用浮点数结算。
- 模型和价格来自服务端 Catalog；禁止在生产前端硬编码价格。
- 每次结算绑定不可变 PriceVersion。
- 充值、扣费、退款、赠送和调账使用不可变双分录账本；修正通过补偿分录完成。
- 支付 webhook、UsageEvent、Settlement 和导入票据都必须幂等。
- 任何请求必须能追到 request ID、实际模型、RouteOffer、PriceVersion、UsageEvent 和账本流水。

## 体验

- 一页一个主任务，同一区域最多一个 Primary action。
- 价格、线路、协议、权限和风险不能为了“极简”而隐藏。
- 模型目录默认策展，不以模型数量或折扣最高为目标。
- 使用“接入到工具”“平台 Key”“线路”“剩余额度”“吊销 Key”等统一词汇。
- 使用“迁移工作环境”和“兼容性报告”，不声称跨厂商会话、隐藏推理或内部缓存可以无损续接。
- 不使用大面积渐变、营销卡片、活动横幅或无意义 AI 发光动效。
- 状态不得只依赖颜色，键盘和屏幕阅读器必须可用。

## 代码与仓库

- 已迁出的旧视觉素材、气候数据面板和生成计划不得重新引入产品工程。
- 不继续向单个 `App.tsx` 堆领域逻辑；按 catalog、keys、usage、billing、desktop 拆分。
- 所有生产数据通过有类型的 API contract 获取；mock 与 fixture 放独立目录。
- 数据库结构只能通过版本化迁移修改。
- 任何 CC Switch、LiteLLM 或其他第三方代码复用都要同步更新许可证 BOM、NOTICE 和归属说明。
- 变更需包含与风险相称的单元、合同、集成或端到端验证。

## 发布门

- 未确定上游商业授权、运营地区、支付/退款规则或数据留存边界时，不得把相应 RouteOffer 或支付功能发布到生产。
- 价格发布、人工调账、权限提升和上游凭证变更必须审计；高风险操作使用双人复核。
- 功能必须可通过 feature flag 关闭，数据库和发布必须可回滚。
