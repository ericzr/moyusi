# Stage 2：模型切换到费用记录纵向切片

状态：本地 mock 闭环已扩展
日期：2026-08-28

## 目标

这一切片只验证一个用户结果：不懂模型协议和路由配置的用户，也能从模型广场选择具体来源，一键切换，完成一次调用，并在费用页看到对应记录。

```text
模型广场
  → 模型详情
  → 比较同型号来源
  → 确认 Moyusi 余额计费
  → 工作台一键切换
  → 自动保留上一个配置
  → 模拟调用
  → 费用、余额和请求记录联动
```

## 已实现状态

### 当前路由

`ActiveRoute` 固定记录实际选择的模型、来源、结算方式、价格、延迟、稳定性、模态和切换时间。界面不再用固定的 GPT 示例冒充当前状态。

### 可恢复切换

`activateSelection` 只在模型或来源真正变化时创建上一版本；`restorePreviousRoute` 可以恢复上一次模型来源。生产版将把同一语义映射到桌面端的检查、备份、原子写入、验证与回滚事务。

### 用量事件

模拟调用生成 `UsageEvent`，事件绑定处理请求的模型与来源，并区分：

- Moyusi 余额扣费；
- BYOK/自有端点的外部费用估算；
- 专属算力已包含的调用费用。

费用页从事件派生余额、本期费用、外部估算和请求数；前端不直接修改一个孤立的余额数字。

### 本地持久化

演示状态只保存模型选择与 mock 用量事件，不包含凭证、请求正文或个人内容。刷新页面后仍能看到刚才的模型和费用记录。

### BYOK 授权边界

来源页可以生成并领取一次性的 mock `ImportGrant`。演示状态仅保存模型账号的绑定状态、授权范围和迁移报告，不保存密钥值；刷新后不会出现任何可恢复的明文凭证。过期授权不能建立连接。

### 迁移预览与确认

迁移不再是静态文案：用户先生成 Codex 或 Claude Code 的差异报告，再确认 mock 应用。报告用“原样、已转换、已重建、待确认”表达每项结果；密钥永远排除在迁移范围外。

## 明确未实现

- 没有真实模型请求；
- 没有真实 Moyusi 扣费或支付；
- 没有收集或保存真实 BYOK；
- 没有写入 Codex、Claude Code 或其他本机软件；
- BYOK 仅模拟 Desktop 领取一次性授权并回传绑定状态；
- 自有端点和专属算力按钮仍只说明下一流程，不伪装成连接成功。

## 验收结果

- 选择统一余额或共享算力来源后能一键切换；
- 当前模型、来源、延迟和稳定性同步更新；
- 原模型可以恢复；
- 模拟调用绑定当前实际来源；
- 费用页与顶部余额同步更新；
- BYOK 费用不会从 Moyusi 余额扣除；
- BYOK 授权状态不包含明文凭证，过期授权不改变连接状态；
- 迁移先给差异预览，确认后才记录 mock 应用；
- 刷新后保留非敏感演示状态；
- 21 个自动化用例及生产构建通过。
