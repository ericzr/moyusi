# 体验与界面规范

## 设计方向

Moyusi 的“极简克制”不是空白、灰色或小字号，而是让用户始终只处理当前决定所需的信息。视觉上保持中性，价格、状态和风险通过结构而不是彩色营销卡片表达。

## 五条体验准则

1. **首屏只有一个主任务。** 模型广场负责选择；工作台首页只显示当前路由与待处理问题。
2. **复杂度按需展开。** 默认显示模型和最终价格；线路、缓存价、协议差异在详情展开。
3. **状态优先于装饰。** 成功、降级、限流、余额不足必须比品牌插画更醒目。
4. **动词清楚。** 使用“接入 Codex”“创建 Key”“充值 US$20”，不用“开始探索”“立即体验”。
5. **数字可比较。** 金额、Token、时延、成功率使用一致单位、对齐和精度。

## 导航

### Web

- 左上：Moyusi 标识。
- 一级导航固定为两个：模型广场、工作台。
- 工作台内部使用轻量子导航：路由、API 与来源、模型与部署、工作环境、用量与计费、账户。
- 公告只以状态点或单行通知出现，不占用固定大横幅。
- 邀请与推广不进入 MVP 导航。

### 桌面端

- 桌面端属于工作台体验，使用工具、路由、模型与部署、工作环境、用量、设置六个子域，不新增站点一级入口。
- 当前工具和当前 Provider 在所有相关页面可见，但不重复做两个顶部切换器。
- 高级代理、故障转移和健康策略归入路由详情，不抢占工作台首页。

## 页面骨架

### 模型广场

```text
模型广场                                       [搜索]
语言模型          图片模型          视频模型
全部供给          闭源 API          开放权重
呈现方式          紧凑列表          卡片          对比

模型                    上下文   协议        起始实付        状态    操作
Claude …                200K     AN / OA     $… / $…        正常    接入
GPT …                   1M       RS / OA     $… / $…        正常    查看来源
开放模型 …              128K     OA          $… / $…        冷/热   查看部署
…
```

- 第一层按生成任务分为语言、图片、视频；第二层再区分闭源 API 与开放权重。不要把“开源/闭源”误当作用户选择模型的首要任务。
- 目录采用“模型列表 + 供给详情”主从结构。同一模型可以展开中转站线路、平台统一余额、BYOK、共享算力、专属算力和自有端点。
- 默认使用高密度紧凑列表；卡片用于按模型浏览，对比视图用于横向比较能力、协议、价格、健康与来源数量。视图切换不改变筛选结果。
- 模型广场不设置营销 Hero、能力宣传条或重复的分类说明；搜索、任务分类、供给筛选和视图切换应在首屏连续可见。
- 不用彩色 Logo 墙做主视觉。
- 同一模型的多条线路默认折叠为一行；行展开后比较线路。
- `起始实付` 必须可展开看到计算方式，不能只显示折扣倍率。
- “正常”表示实时健康，不等于 SLA；鼠标/点击可看最近窗口。
- 闭源 API、开放权重、共享端点、专属部署和自有端点使用文字标签，不用容易混淆的彩色图标代替。
- 开放模型的模型身份与部署身份分层展示；不同 revision、量化或 chat template 不能静默折叠为完全相同的线路。

### 模型详情

```text
返回模型
模型名                              [接入]
一句话用途 · 精确 model id

能力与限制          价格              线路
上下文               输入              稳定
工具调用             输出              低价
支持协议             缓存              指定线路

线路证据
24h / 30d 成功率 · TTFT / 总时延 p50/p95 · 样本量 · 探测地区 · 最后更新

兼容工具
Codex  Claude Code  Gemini CLI

数据与条款
地区 / 日志 / 正文留存 / 上游政策
```

- `测得`与`承诺`使用不同标签：历史健康指标不能写成 SLA，SLA 必须链接到计算与补偿规则。
- 样本不足、探测过期或地区不匹配时显示“证据不足”，不沿用绿色“正常”。
- 不展示综合“靠谱分”；让用户展开查看价格、性能、供应和数据四类证据。

### 接入确认

接入是产品最关键的界面，使用单页三段式，不做多步轮播：

1. 目标：模型、线路偏好、工具。
2. 权限：Key、金额上限、到期。
3. 变更：Base URL、模型 ID、要修改的本地配置。

底部只有“取消”和“在桌面端确认”。Web 不直接声称本地配置已完成。

### 工作台

```text
工作台            路由  API 与来源  模型与部署  工作环境  用量与计费  账户

当前工具          Codex
活动路由          GPT … · 稳定策略                  [切换]
状态              本地代理正常 · 备用线路可用

需要处理
供应商 B 余额偏低                                 [查看]
```

- 总览不同时展开 Key、账本、调用记录和账号设置。
- 路由页以 Provider Profile 和工具为主，不以云端供应商后台为主。
- 统一余额与 BYOK 必须使用不同计费标识；外部费用不可混入 Moyusi 余额。
- 账户与设备放入工作台，不设置“我的”一级入口。

### 模型与部署

```text
模型与部署                                      [连接自有端点]

Qwen … · 开放权重
共享端点       warm      $… / 1M tokens                [加入路由]
专属端点       未创建    A100 … / 小时                  [配置]
自有端点       健康      vLLM … · 私有网络              [查看]
```

- 默认只显示可用方式、状态和当前成本，硬件与引擎参数在详情展开。
- 创建专属部署前同时显示最低持续成本、预计月成本、启动时间和缩容/删除规则。
- `warm`、`cold`、`starting`、`unavailable` 是运行状态，不用笼统的“正常”覆盖冷启动。
- 外部算力账单使用“供应商计费”或“本地估算”，不能混入 Moyusi 余额。

### 工作环境

```text
工作环境                                         [部署到软件]

日常编程                         v12 · 2 个目标
Codex                            已部署 · exact 8 / adapted 2
Claude Code                      有更新 · unsupported 1

资产
MCP 4     Skills 6     Prompts 3     记忆 18     知识库 2
```

- 首屏以 WorkspaceProfile 为主，不并排放五个资产后台。
- 迁移预览先显示目标软件、版本、权限变化和不支持项，再展示字段 diff。
- 每个结果必须使用 `原样`、`已转换`、`已重建`、`不支持` 四种可理解状态。
- Secret 只显示“未绑定/已绑定”和作用域，不提供从另一软件复制明文的操作。
- 会话迁移使用“创建检查点并在新会话继续”，不得使用“无损续接原会话”。

### API Key 创建成功

- 弹窗顶部明确“只显示这一次”。
- Key 使用等宽字体，默认全部显示；提供复制。
- 复制后 CTA 是“接入到工具”，不是“关闭”。
- 不显示庆祝动画，不引导创建第二个 Key。

## 视觉系统建议

### 色彩

- 背景：中性白/近黑。
- 文字：一个主文字色、一个次文字色。
- 分隔：低对比 hairline。
- 强调色：只选一个品牌色，用于主操作和焦点。
- 状态色：成功、警告、错误只用于真实状态，不用于供应商装饰。
- 模型厂商色只在 16–20 px 小标识中出现，不能染整张卡片。

### 字体与数字

- 界面中文：系统无衬线或经过授权的中文字体。
- 英文、model id、金额和技术字段：等宽或 tabular numbers。
- 正文最小 13 px，关键价格不小于 16 px。
- 金额精度由计费单位决定；列表避免不必要的 4–6 位小数。

### 尺寸

| Token | 建议 |
| --- | --- |
| 页面最大宽度 | 1200–1280 px |
| 左导航宽度 | 208–224 px |
| 行高 | 紧凑 44 px，默认 52 px |
| 圆角 | 6–10 px，不使用大面积 24 px 营销圆角 |
| 基础间距 | 4 px 系统，常用 8/12/16/24/32 |
| 边框 | 1 px 中性 hairline |
| 阴影 | 仅浮层，页面卡片默认无阴影 |

### 动效

- 120–180 ms，用于悬停、展开、状态切换。
- 不对金额、余额和价格做滚动数字动效。
- 调用测试可显示阶段进度，但避免无限“AI 发光”动画。
- `prefers-reduced-motion` 下完全可用。

## 组件规则

### Button

- 同一区域最多一个 Primary。
- 主动词使用对象：`接入 Codex`，不是 `确认`。
- 破坏性操作使用文本明确对象：`吊销 Key`。
- 图标按钮必须有可访问名称和 Tooltip。

### Badge

- 只表示协议、状态、线路或权限。
- 同一行最多 3 个，更多内容折叠为“+2”。
- 不用 Badge 承载长营销文案。

### Table

- 模型、用量、账本以表格为主，不强制卡片化。
- 金额右对齐；名称左对齐；状态居中或左对齐但全站一致。
- 行点击与行内按钮不能冲突；详情使用明确的展开控制。

### Dialog

- 只用于创建 Key、确认接入、吊销和敏感操作。
- 模型详情与用量详情使用页面或侧栏，不用层层弹窗。
- Dialog 关闭不得丢失已付款或已完成的外部状态。

### Empty state

- 一句话解释为什么为空。
- 一个主操作。
- 不放插画、三张教程卡或多个文档链接。

## 文案词汇表

| 推荐 | 避免 | 原因 |
| --- | --- | --- |
| 平台 Key | 智能 Key（未解释时） | 前者说明归属，后者容易营销化 |
| 接入到工具 | 安装模型 | 实际是在写配置，不是在下载模型 |
| 线路 | 通道/分组混用 | 保持统一心智 |
| 起始实付 | 官方价 0.03x | 先给真实金额，再说明相对关系 |
| 剩余额度 | 账户信用 | 对预付消费更直观 |
| 调用记录 | 对话历史 | 默认不存对话正文 |
| 吊销 Key | 删除 Key | 吊销更符合不可逆凭证语义 |
| 充值 | 购买模型 | 避免所有权误解 |

## 原型收敛决策

### 保留

- 冷静的黑白基础、紧凑表格、等宽技术字段。
- 从模型目录发起“接入”的交互。
- 工具、线路、Key、用量之间的关联感。
- 暗色模式。

### 收敛

- 将“中转 / 控制台 / 我的”改为清晰名词导航。
- 图片/视频进入模型广场一级任务分类，但首版只覆盖模型选型、供给比较与接入；创作画布、素材库和编辑器不进入 MVP。
- 不在一个页面同时显示模型市场、供应商编辑、钱包和用量图。
- 上游配置编辑从 Web 页面分离到桌面领域。
- 去掉演示用热力背景和非必要动态数据，保留真实趋势图。

### 已替换

- 旧占位品牌、域名和样式命名。
- 看似真实的示例凭证与供应商配置。
- 绝对定位导入页面、截图素材和无关气候数据组件。

### 后续替换

- 硬编码模型、价格、余额、健康度和 Key fixture。
- 单文件内存状态与无类型的数据读取。

## 可访问性底线

- 所有功能键盘可达，焦点状态明显。
- 状态不只依赖颜色；必须有文字或图标语义。
- 表格在窄屏转换为可读的键值组，不水平压缩到不可读。
- 对比度达到 WCAG 2.2 AA。
- 复制 Key、充值成功、接入成功使用可被屏幕阅读器读到的状态消息。
